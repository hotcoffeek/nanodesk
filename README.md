# NanoDesk для Android

Телефонный клиент для NanoDesk: подключение к ПК по ID (через интернет, без своего сервера) или по IP в локальной сети.

## Что внутри

* Подключение по ID: тот же протокол, что и в ПК-версии (MQTT-сигнал + пробивка NAT по UDP + резервный канал через брокеры), SRP-6a для пароля, AES-256 + HMAC для сеанса.
* Режимы «тачпад» и «касание», щипок — масштаб, два пальца — прокрутка, долгое нажатие / два пальца — правый клик, «тап и тянуть» — перетаскивание.
* Клавиатура телефона, панель клавиш (Esc, Tab, Ctrl/Alt/Shift/Win, стрелки, F1–F12, сочетания), русский текст через буфер обмена.
* Файлы: просмотр папок на ПК, скачивание на телефон, отправка файлов на ПК.
* Фоновый режим: пока идёт сеанс, работает служба переднего плана с уведомлением (кнопка «Отключить»); при потере связи сеанс восстанавливается сам.
* Темы: тёмная, OLED, светлая и две «простые» чёрно-белые. Простая тема сразу отключает все анимации (отдельный переключатель тоже есть).

## Ограничения первой версии

* Только JPEG-видео (H.264 на телефоне пока нет) — для телефона этого достаточно.
* Телефон — только клиент (подключиться к нему нельзя).
* Приложение не проверялось на реальных устройствах — если что-то не работает, пришлите текст ошибки.

## Проверка сетевого ядра

В `test/Loop.java` — проверка на «петле»: SRP, шифрование канала, надёжный UDP и передача 400 КБ кадра между двумя узлами в одном процессе.
